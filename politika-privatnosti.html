Politika privatnosti

Ružica parking prikuplja, čuva, evidentira, pohranjuje, štiti, organizira, obrađuje, prenosi i ima pristup osobnim podacima koje nam pošaljete na web stranici https://ruzicaparking-zagrebairport.hr sukladno Općoj uredbi o zaštiti podataka.

Kontakt forme

Osobne podatke koje nam pošaljete putem kontakt forme na web stranici koristimo za daljnju komunikaciju s Vama u svrhu ostvarivanja potencijalne poslovne suradnje.

Kolačići

Google Analytics je Googleov alat za analizu koji pomaže vlasnicima web stranica i aplikacija da saznaju kako njihovi posjetitelji koriste značajke njihovih web stranica i aplikacija.

Može koristiti skup kolačića za prikupljanje informacija i izvješćivanje o statistici korištenja web stranice bez otkrivanja identiteta pojedinačnih korisnika Googleu.

Glavni Google Analytics kolačić je “__ga.” Saznajte više o Analytics kolačićima i informacijama o privatnosti

Ugrađeni sadržaj s drugih web stranica

Članci na ovoj web stranici mogu sadržavati ugrađeni sadržaj (npr. videozapise, slike, članke itd.).

Ugrađeni sadržaj s drugih web stranica ponaša se na isti način kao da je posjetitelj posjetio tu drugu web stranicu. Ove web stranice mogu prikupljati podatke o vama, koristiti kolačiće, ugraditi dodatno praćenje treće strane i pratiti vašu interakciju s tim ugrađenim sadržajem, uključujući praćenje vaše interakcije s ugrađenim sadržajem ako imate račun i prijavljeni ste na web mjesto.

Analitika

Naša web stranica koristi Google Analytics kolačiće za anonimnu analizu vaše aktivnosti kako bismo dobili informaciju je li iskustvo korištenja naše web stranice dobro i kako ga možemo poboljšati.

Koliko dugo čuvamo vaše podatke?
